# Analytics Events

The local event layer supports:

search_submitted, search_zero_results, search_result_clicked, filter_applied, product_viewed, product_saved, compare_added, comparison_viewed, configurator_started, configuration_changed, configuration_saved, configuration_completed, room_composer_started, room_scene_saved, visual_search_uploaded, fit_check_completed, dealer_selected, lead_started, lead_submitted, appointment_booked, project_created, project_shared.

Events include event ID, session ID, optional user/product/configuration/project/dealer IDs, locale, timestamp and consent state.
